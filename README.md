# Noor Stor (Next.js + JSON Server)

Simple e-commerce demo built with Next.js (Pages Router) and json-server.

## Requirements

- Node.js 18+
- npm

## Install

```bash
npm install
```

## Run in development

Open 2 terminals in the project folder.

Terminal 1 (frontend):

```bash
npm run dev
```

Terminal 2 (API/db):

```bash
npm run api
```

## URLs

- App: http://localhost:3000
- API: http://localhost:4000/products

## Build

```bash
npm run build
```
